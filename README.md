# PhantomShell 👻

**A Haunted AI Terminal Possessed by Forgotten Code & Ancient Spirits**

*Built for the Hacktoberfest Open-Source AI Challenge: Week 4 — "Ghost in the Machine"*

---

## 🎃 Concept & Theme Inspiration

Halloween and Día de los Muertos remind us that the boundary between past and present is delicate. In computer science, billions of lines of forgotten code, abandoned languages, and crashed processes linger in dead repositories and unallocated drive sectors.

**PhantomShell** is an offline, spooky AI-infused terminal environment that simulates a system "possession." As you execute commands (`ls`, `git`, `rm`, `cd`, `python`, `kill`), an open-weight ghost agent whispers haunting commentary, ancestral computing memories, and eerie philosophical reflections back into your shell.

---

## ⚡ Features

- 💀 **Spectral Terminal Interface:** Retro CRT monitor aesthetic with scanlines, phosphorescent green glow, and flickering screen simulation.
- 🕯️ **Eerie Command Whispers:** Intercepts standard POSIX and developer commands to deliver cryptic, thematic folklore.
- 📴 **100% Offline Possession:** Runs entirely on-device with zero telemetry or cloud model API fees.
- 📜 **Día de los Muertos Remembrance:** Reawakens dead programming spirits (Ada Lovelace, ancient Lisp daemons, kernel panics of 1989).

---

## 🚀 Quickstart

```bash
pip install flask
python app.py
```

Open `http://localhost:5004` to speak with the ghosts in the machine.
